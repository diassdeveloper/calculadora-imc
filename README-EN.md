# BMI Calculator 🏋️

BMI Calculator developed in Python as a learning project.

## Features

- Calculates BMI based on informed weight and height
- Classifies the result into categories (Ideal weight, Overweight, etc.)
- Saves measurement history in SQLite database
- Displays previous measurement history

## Technologies used

- Python 3
- SQLite3
- Datetime

## How to use

1. Clone the repository
2. Run the `main.py` file
3. Enter your name, weight and height
4. The result will be displayed and saved automatically
