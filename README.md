# Calculadora de IMC 🏋️

Calculadora de IMC desenvolvida em Python como projeto de aprendizado.

## Funcionalidades

- Calcula o IMC com base na massa e altura informadas
- Classifica o resultado em categorias (Peso ideal, Sobrepeso, etc.)
- Salva o histórico de medições em banco de dados SQLite
- Exibe histórico de medições anteriores

## Tecnologias utilizadas

- Python 3
- SQLite3
- Datetime

## Como usar

1. Clone o repositório
2. Execute o arquivo `main.py`
3. Informe seu nome, massa e altura
4. O resultado será exibido e salvo automaticamente
